# Porygon source lock — v8

Paper: **Porygon: Scaling Blockchain via 3D Parallelism**, Wuhui Chen et al., IEEE ICDE 2024, DOI `10.1109/ICDE60146.2024.00153`.

Primary public paper copy used by this reproduction: `https://www.comp.hkbu.edu.hk/~henrydai/pubs/Porygon_ICDE24__Henry.pdf`.

No verified official public Porygon source repository was located for this MBE reproduction. Therefore this is a paper-driven reimplementation, not a source-port claim.

The paper mechanisms represented here are: storage/consensus separation, Witness→Ordering→Execution→Commit processing, Cross-Batch Witness, execution sub-committee sharding, global ordering before execution, and Single-Shard Execution / Multi-Shard Update for cross-shard transactions.
